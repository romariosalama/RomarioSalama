Featured projects
🚦 Autopolis · AI traffic simulation · autopolis.app

A live 3D city where a reinforcement learning agent runs the traffic lights. You can switch between fixed timers and the AI and watch the wait times change.

Trained a PPO agent that cuts average wait time 24% vs. the best fixed-timer schedule, and 29% on a bigger city it never trained on
Streams 700+ cars in real time over WebSockets to a React + Three.js frontend
Simulation engine runs headless at ~590x real time for training
