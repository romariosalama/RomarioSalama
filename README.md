## Projects

### [Autopolis](https://github.com/romariosalama/autopolis) | AI Traffic Simulation

**Live:** [autopolis.app](https://autopolis.app)

A real-time 3D city where a reinforcement learning agent controls the traffic lights. Switch between fixed timers and the AI and watch wait times change live.

- Trained a PPO agent that cuts average wait time by **24%** vs. the best-tuned fixed timer, and **29%** on a larger city it never trained on
- Streams **700+ vehicles** in real time over WebSockets to a React and Three.js frontend
- Simulation engine runs headless at **~590x real time** for training

<a href="https://autopolis.app"><img src="https://raw.githubusercontent.com/romariosalama/autopolis/main/docs/screenshot.png" alt="Autopolis" width="640" /></a>

**Built with:** Python, FastAPI, React, Three.js, WebSockets, PyTorch, Stable-Baselines3, Docker, AWS

### [Callcade](https://github.com/romariosalama/callcade) | Sales Call Practice Game

**Live:** [callcade.app](https://callcade.app)

Practice sales calls by talking out loud to AI buyers, each with hidden moods, problems, and objections.

- **352+ users** across 40 buyers, 5 industries, and 4 game modes
- Server-authoritative call engine that validates every outcome server-side
- Automatic fallback across 4 LLMs, secure accounts with email verification, and **77 automated tests** in CI

**Built with:** Python, FastAPI, JavaScript, SQLite, LLMs, AWS Lightsail, AWS SES
